# Stable Scripts Hub

存放经过实际测试、可直接运行并长期维护的自动化脚本与工具。主要涵盖青龙面板定时任务、傻妞 (sillyGirl) 机器人插件以及 Linux 系统运维脚本。

**核心原则：** 所有进入主分支的脚本必须是“已完成、已测试、可直接使用”的稳定版本。

## 📂 目录导航
* `scripts/sillygirl/`：傻妞机器人交互插件（如青龙节点管理、变量合并等）
* `scripts/qinglong/`：适用于青龙面板的自动化脚本
* `scripts/linux_ops/`：Linux 服务器资源监控、Docker 容器管理脚本
* `config/`：脱敏后的配置示例文件
* `archive/`：已归档的历史脚本

## 🚀 快速使用
1. 在 `scripts/` 目录下找到所需脚本。
2. 查看脚本头部的注释说明（包含运行环境、依赖和配置方法）。
3. 复制对应的配置示例 `.env.example`，在本地重命名为真实配置文件（如 `.env`）并填入你的参数。
4. 运行脚本。

## 🛡️ 安全与配置
本仓库**严禁**提交任何私人 Token、Cookie、API Key、密码或服务器真实 IP。
所有涉及敏感信息的变量，必须通过读取外部配置文件、环境变量或系统内部数据库传入。

## 📌 版本说明
遵循简单的语义化版本：
* `v1.0.0`：主版本（功能重构或不兼容的配置修改）
* `v1.1.0`：次版本（向下兼容的新增功能，如新增批量处理能力）
* `v1.1.1`：修订号（向下兼容的 Bug 修复，如修复 URL 解析错误）

## 📝 贡献与维护
如果你需要修改逻辑：
1. 优先保证脚本能正常运行，不要为了纯粹的代码规范破坏原有逻辑。
2. 确保配置清晰，出问题时容易排查日志。
