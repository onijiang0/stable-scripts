# Stable Scripts Hub

存放经过实际测试、可直接运行并长期维护的自动化脚本与工具。目前包含青龙面板定时任务脚本，以及傻妞 (sillyGirl) 机器人插件（含服务器运维监控能力）。

**核心原则：** 所有进入主分支的脚本必须是“已完成、已测试、可直接使用”的稳定版本。

## 📂 目录导航
* `ql/`：青龙面板定时任务脚本（签到、积分、活动类，Python / JS 混排）
* `sillygirl/`：傻妞机器人插件（直接放入傻妞插件目录使用）

## 🚀 快速使用
1. 在 `ql/` 或 `sillygirl/` 目录下找到所需脚本。
2. 查看脚本头部的注释说明（包含运行环境、依赖、变量名和 cron 建议）。
3. 在青龙面板 / 傻妞后台新建任务，粘贴脚本内容并配置对应环境变量。
4. 运行脚本。

> ⚠️ `ql/` 下的脚本依赖青龙容器内的运行环境（如 `cmcc_sign.js` 需要 `../tools/env.js`），
> **不能直接在本机运行**，请放入青龙面板使用。

## 🛡️ 安全与配置
本仓库**严禁**提交任何私人 Token、Cookie、API Key、密码或服务器真实 IP。
所有涉及敏感信息的变量，必须通过读取外部配置文件、环境变量或系统内部数据库传入。

## 📌 版本说明
遵循简单的语义化版本：
* `v1.0.0`：主版本（功能重构或不兼容的配置修改）
* `v1.1.0`：次版本（向下兼容的新增功能，如新增批量处理能力）
* `v1.1.1`：修订号（向下兼容的 Bug 修复，如修复 URL 解析错误）
