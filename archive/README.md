# archive — 归档区

存放**已停用但需要保留备查**的历史脚本。这里的内容不再被青龙面板或傻妞加载，
只作为参考与回滚备份，**不要**把这里当作可运行脚本的目录。

## 归档规则

1. 用 `git mv` 移动，**不要** `rm` 后再重新创建 —— 这样 Git 会识别为 rename，
   文件历史完整保留，`git log --follow -- <path>` 仍能追溯。
2. 每一批归档放进一个 `YYYY-MM-DD-主题/` 目录，目录内**必须**有 `NOTE.md`，
   写清四件事：**归档日期 / 归档原因 / 被谁取代 / 恢复方法**。
3. 归档后**必须**同步停用青龙 / 傻妞里的对应定时任务。
   归档只是把文件移出 `ql/`，面板里那条 cron 不会自动消失 —— 不处理会天天报错。
4. 在本文件下方的索引表登记一行。

## 为什么不用「直接 git rm」

直接删也能从历史里捞回来，但要先知道 commit sha 才能 `git show <sha>:<path>`，
属于「记得住才找得回」。放进 `archive/` 是把找回成本从「记得住 sha」降到「打开目录就看得见」，
代价只是仓库里多几个不参与运行的文件。
